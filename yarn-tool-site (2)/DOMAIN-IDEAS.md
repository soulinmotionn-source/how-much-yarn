## Recommendation

**howmuchyarn.com** is the strongest pick: it matches the highest-volume head
keyword, it's available, and it's instantly understandable. Runner-up:
**yarnmeter.com** for a more brandable feel.

Once you choose: set `SITE_URL` in `build.py` to `https://www.<yourdomain>.com`
(no trailing slash), run `python3 build.py`, re-zip, and deploy. See
`UPDATE-GUIDE.md` for the full flow.
